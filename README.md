# voicepipe Homebrew tap

[voicepipe](https://github.com/carloswestman/voicepipe) — talk to your terminal
agents by voice, hands-free and fully local.

## Install

```sh
brew install carloswestman/tap/voicepipe
```

Then run the one-time setup:

```sh
voicepipe init     # downloads the whisper model (~1.5 GB)
voicepipe doctor
```
